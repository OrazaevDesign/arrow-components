# Карточка товара — спецификация поведения

Как карточка должна работать: что кликается, что показывается при наведении, что видно
на десктопе и на таче, что делает гость. Здесь только поведение. Разметка — в `{variant}.md`,
значения — в CSS вариантов и `SKILL.md`. Правило, которого здесь нет, не считается
договорённостью: его надо спросить у владельца и дописать сюда.

Версия компонента на момент записи — 3.0.0 (08.10.2026).

## Общие правила

1. **Корень — контейнер, не ссылка.** Кликают отдельные ссылки: фото, бренд, название,
   рубрика. Внутри карточки есть кнопки (избранное, корзина, стрелки), а кнопка внутри
   ссылки — невалидная разметка.
2. **Каждая ссылка подсвечивается сама.** Наведение на бренд не подсвечивает название,
   и наоборот. Фокус — `:focus-visible` на каждой ссылке отдельно.
3. **Тултипов в карточке нет** (с 3.0.0, решение владельца 08.10.2026). Ни на флаге, ни на
   избранном. Страну флага называет `alt` картинки, кнопку избранного — `aria-label`.
4. **Анимации гаснут** при `prefers-reduced-motion: reduce`: кросс-фейды, скрим, стрелки.
5. **Ширина ряда не прыгает.** Если строка включена хотя бы у одной карточки, место под неё
   есть у всех: пустой резерв отзывов (`.pcard__feedback--empty`) и заглушка индикатора
   галереи (`.pcard__slider-spacer`) у товара с одним фото.

## Фото

| Действие | Десктоп (мышь) | Тач (телефон, планшет) |
|---|---|---|
| Наведение | гаснет затемнение 5% (скрим); фото не зумится, тени нет | — |
| Наведение на стрелку галереи | скрим остаётся погашенным: hover держит вся медиа-область, а не ссылка (с 2.0.2/2.0.3) | — |
| Клик / тап | переход на товар | переход на товар |
| Листание кадров | только стрелками | свайп влево/вправо |
| Уход курсора с фото | кадр **не** сбрасывается на первый (с 2.0.1) | — |

- **Позиция курсора кадр не переключает.** Hover-зоны убраны 07.10.2026: со стрелками они
  мешали, кадр менялся от простого движения мыши.
- **Свайп** листает по одному кадру. Вертикальный жест отдаётся странице (`touch-action: pan-y`).
  После свайпа клик по фото гасится, чтобы жест не открыл товар.
- **Кадры прогреваются** при первом наведении или касании, чтобы новый кадр не «вспыхивал».

### Стрелки галереи

- Есть только при **двух кадрах и больше**.
- Листают **по кругу**: с последнего кадра «вперёд» ведёт на первый.
- Видны только на десктопе (`hover: hover`), при наведении на фото. В покое стоят за краем
  фото и срезаны, при наведении въезжают внутрь (0.3s).
- С клавиатуры появляются по `:focus-visible`. Обычный `:focus-within` не годится:
  после клика мышью кнопка держит фокус, и стрелки залипали видимыми.
- На таче и в мобильной вью (`.pcard--mobile`) стрелок нет: листает свайп.

### Индикатор кадров

- Точки под фото — по числу кадров, активная выделена.
- Больше пяти кадров — окно из пяти точек, лента точек едет за активной, крайние уменьшены.
- **В каруселях блоков ниже десктопа (<1024) точек нет**, а свайп по фото листает ленту
  карточек, а не кадры. На десктопе листание кадров — стрелками.

## Флаг страны

- Слева сверху на фото. Декоративный для мыши: клик и наведение проходят к фото.
- Подсказки при наведении нет. Название страны — в `alt`.

## Избранное

- Справа сверху на фото, компонент `button-favorites`; состояние — `aria-pressed`.
- **Вошедший покупатель:** клик переключает сразу (оптимистично), сервер подтверждает
  (`POST /my/product/favorites/{id}/toggle`). Ошибка — отметка откатывается. Пока запрос
  идёт, повторный клик игнорируется.
- **Гость: клик открывает окно входа** (решение владельца 08.10.2026), избранное не
  переключается.
  - Окно строит модуль витрины `authTrigger` по атрибуту `[data-auth]` на кнопке — тот же
    приём, что у шапки `awds-header`.
  - Модуля на странице нет — гость уходит на `/my/authorization/?return_url=<текущая страница>`.
  - Вошёл ли посетитель, говорит `/atlas/webapi/user-data.json` (`userdata.isLogin`) — один
    запрос на страницу, общий для всех блоков.
  - Сервер ответил на переключение 401 или 403 — отметка откатывается, гость уходит на вход.
- Подсказки «Добавить в избранное» нет.

## Бейджи

Слева снизу на фото (в `brand-first` — по центру). Декоративные: клик проходит к фото.
Скидка — `badge-market-percent`. Товара нет в наличии — бейдж скидки не показывают.

## Текст

- **Цена** — компонент `price`: обычная, со скидкой (акцентная + старая зачёркнутая),
  «Нет в наличии». В `button-price` цена — подпись кнопки корзины.
- **Бренд** — ссылка на бренд, есть во всех вариантах.
- **Название** — ссылка на товар, **одна строка** с многоточием.
- **Рубрика** — ссылка на категорию, необязательна.
- **Отзывы** — `★ рейтинг 💬 счётчик`, **не ссылка**, без hover. Последняя строка карточки,
  под корзиной. Счётчик склоняется: 1 отзыв, 2 отзыва, 5 отзывов.

## Корзина

Зона `.pcard__cart`, две вью сложены в одном месте, переключаются кросс-фейдом по
`data-cart-state`:

| Состояние | Что видно | Что делает |
|---|---|---|
| `button` (по умолчанию) | «В корзину», primary 400 | открывает окно быстрого просмотра витрины (выбор вариации, доставка, количество) |
| `added` | «В корзину» → addition 400, иконка справа | ссылка на корзину |
| нет в наличии | кнопка `disabled` | ничего |

- Окно быстрого просмотра — штатная модалка Atlas по атрибутам
  `data-selector="mini-product-card:root"`, `data-product-id`, `data-product-variation-id`.
  Своего JS не нужно; работает и для гостя.
- Состояние `added` блоки пока не выводят: в данных SSR нет признака «товар в корзине»
  (вопрос открыт на доске).
- Степпера количества нет с 2.0.0.

## Мобильная вью

`.pcard--mobile` — не ступень размера, а вид для узкой колонки: цена мельче (control 700/100),
бейджи и избранное на ступень меньше, стрелок галереи нет. Поведение остальное — как на таче.

## Где живёт поведение

| Что | Где |
|---|---|
| Hover, кросс-фейды, видимость стрелок | CSS варианта (`product-card-*.css`) |
| Галерея: стрелки, свайп, точки | `wireGallery` — эталон в `product-card-price-first.md`, копия в `script.js` блока |
| Избранное, вход гостя | `script.js` блока-потребителя (эталон — `awds-category-product-slider`) |
| Корзина: модалка | атрибуты Atlas в разметке, JS не нужен |

Блок, который выводит карточку, обязан повторить JS из этой таблицы: CSS компонента
поведение избранного и галереи не даёт.
