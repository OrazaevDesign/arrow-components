# textarea-combi — журнал версий

## 1.0.2 — 2026-09-25 — PATCH · visual
Ячейка form-control/{default,success,error,autofill}/bg-focus переехала в студии: --surface-bright → --primary-container-base. Код и документация переведены на новую цель.

## 1.0.1 — 2026-09-25 — PATCH · visual
Фон стал плоской заливкой: из базы убран linear-gradient(chroma → bg), ячейки chroma-* компонентом больше не читаются, сняты регистрация @property и строка transition по ним. Градиент был виден в состоянии фокуса.
Потребителю: Разметка и классы прежние. Фон контрола теперь ровный — заметно там, где градиент был виден (в состоянии фокуса). Потребителям с копией CSS нужна пересборка секции.

## 1.0.0 — 2026-09-16 — MAJOR
Первый релиз. Компонент собран с нуля по секции ↪ textarea-combi (44:75250): многострочное поле с меткой внутри рамки, шесть тонов, четыре ступени, 300 якорей ячеек. Метка НЕ плавает — у многострочного поля нет центра, поэтому она всегда наверху; состояния «заполнено» здесь не существует.
Потребителю: Новый компонент, у потребителей ничего не ломается. Берётся вместо textarea там, где форма построена на combi-контролах: способы подписи в одной форме не смешивают.
