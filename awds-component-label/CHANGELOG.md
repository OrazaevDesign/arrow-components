# label — журнал версий

## 1.0.9 — 2026-09-16 — PATCH · visual
Починка: 41 ссылка на приватные ячейки State и Size заменена ролями и базовыми шкалами с якорями. Подпись не получала ни размеров, ни гашения — слоты иконок рисовались 300x300 вместо 20/24/28, зазоров не было вовсе, отступы нулевые: 34 элемента превью плюс 16 у formfield, который держит её инстансы. В теме заведены три ячейки label/color, label/mark/border, label/mark/bg. Толщина обводки образца переведена с литерала 1px на --awds-space-px. В макете ось-заглушка type= из восьми значений разобрана на control и три булевых show-*, набор 24 ячейки -> 15.
Потребителю: Пересобрать копию CSS: подпись теперь получает размеры контрола, зазоры и гашение, которых раньше не было.

## 1.0.6 — 2026-09-01 — PATCH
Ссылки на слой State переведены с mode-less имён на плоские суффиксные: opacity/control-disabled, opacity/control-enabled → те же ячейки с суффиксом -rest. Значение не изменилось: у этих ячеек все четыре состояния (rest, hover, focus, active) несут одно и то же, поэтому -rest подставлен без потери смысла. Смысл правки — снять зависимость компонента от блоков-обёрток темы, которые переключают mode-less имена за него и новых компонентов уже не покрывают. Этап Э2 плана «Уплощение слоя State».
Потребителю: Ничего делать не надо: имена читаются внутри CSS компонента, разметка, классы и вид не менялись.
