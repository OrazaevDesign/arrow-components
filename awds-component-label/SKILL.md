# Label ArrowDS

Строка «контрол — текст», из которой собираются все восемь типов макета: от голой подписи к полю до строки выбора цвета товара. Компонент **композиционный**: сам он рисует только текст, отступы и две мелочи (кружок-образец и знак вопроса), а сами контролы приходят готовыми из своих скиллов.

## Разметка

Голая подпись к полю:

```html
<label class="lbl lbl--400" for="city">
  <span class="lbl__body">
    <span class="lbl__text">Город доставки</span>
  </span>
</label>
```

Строка с чекбоксом — контрол кладётся первым, `<label>` оборачивает всё, поэтому клик по тексту переключает его:

```html
<label class="lbl lbl--400">
  <span class="checkbox">
    <input class="checkbox__input" type="checkbox">
    <span class="checkbox__box">…</span>
  </span>
  <span class="lbl__body">
    <span class="lbl__text">Согласен с условиями</span>
  </span>
</label>
```

Обрати внимание: контрол размечается `<span class="checkbox">`, а **не** `<label class="checkbox">`, как в его собственном скилле. Вложенные `<label>` — невалидный HTML, а внешняя обёртка нам нужна как раз для клика по тексту. Классы `.checkbox` при этом работают: у чекбокса они не привязаны к тегу.

Остальные типы — [references/label-default.md](references/label-default.md).

## Восемь типов — это состав, а не классы

| Тип в Figma | Чем выражен |
|---|---|
| Label | только `.lbl__body` с текстом |
| Label + Help | + `.lbl__help` после тела |
| Icon | + `.lbl__icon` перед телом |
| Checkbox / Radio / Switch | + компонент контрола перед телом |
| Checkbox + Color | + `.lbl__mark` внутри тела, перед текстом |
| Checkbox + Flag | + `.lbl__mark.lbl__mark--plain` с иконкой |

Классов под типы нет намеренно: они отличаются только тем, какие элементы стоят в строке. Восемь классов заставляли бы дублировать в атрибуте то, что уже видно в разметке, и держать их синхронными.

## Размеры

| Класс | Строка | Контрол | Текст | Образец | Подсказка |
|---|---|---|---|---|---|
| `lbl--300` | 20px | 20 | 14/20 | 20 | 16 |
| `lbl--400` | 24px | 24 | 14/20 | 20 | 16 |
| `lbl--500` | 28px | 28 | 14/20 | 24 | 20 |

**Текст не зависит от размера.** Во всех трёх это 14/20 по шкале `control` — размер меняет вложенный контрол, вертикальный отступ текста и мелкие элементы. Поэтому `.lbl--{N}` — про контрол и воздух, а не про кегль.

Высоту строки задаёт контрол; без контрола — текст со своим паддингом: 24 у размеров 500/400 и 20 у 300. Отсюда особенность макета: **у типа без контрола 500 и 400 совпадают полностью**.

## Размер контрола задаёт подпись

Внутри `.lbl--{N}` вложенный чекбокс, радио или переключатель получает свою ступень автоматически — мост кормит их size-аккумуляторы из `square-{N}`. Ставить `.checkbox--500` рядом с `.lbl--500` не нужно.

Мост **сильнее** класса контрола: `.lbl--500 .checkbox` весит (0,2,0) против (0,1,0) у `.checkbox--200`. То есть внутри подписи ступень всегда диктует подпись — пара «подпись N — контрол N» единственная в макете, а рассинхрон был бы молчаливым. Нужна нестандартная пара — задавай `--awds-checkbox-icon` и соседние переменные инлайном на самом контроле.

## Три вещи, которые легко сделать неправильно

1. **Взять `gap` из `square-{N}-gap`.** Соблазн понятен — контрол же из этой шкалы. Но там 6 на размерах 300/400 и 8 только на 500, а в макете зазор одинаковый и равен `space-2` (8) на всех трёх. Считано по всем размерам: 36−28 = 32−24 = 28−20.
2. **Растянуть тело на всю ширину.** `.lbl__body` идёт по контенту (`flex: 0 1 auto`), и это видно только на типе Label + Help: в макете знак вопроса стоит вплотную за текстом, а не у противоположного края. Растянутое тело уводит подсказку вправо, и связь «вопрос относится к этой подписи» рвётся тем сильнее, чем шире форма. Нужен «?» у правого края — это композиция уровня страницы: `margin-inline-start: auto` на `.lbl__help`.
3. **Вложить `<label class="checkbox">` внутрь `<label class="lbl">`.** Невалидно, и браузер такую пару разбирает непредсказуемо. Внутри — всегда `<span class="checkbox">`.

## Доступность

- Подпись к отдельному полю связывается через `for` + `id`. Строка с контролом внутри в `for` не нуждается: `<label>` оборачивает сам `<input>`.
- **Знак вопроса — настоящая кнопка**, а не `<span>`: `<button type="button" class="lbl__help" aria-label="Зачем это нужно">`. За ним стоит объяснение, значит до него должны доходить клавиатура и скринридер. Фокус на нём виден собственным кольцом.
- **Образец цвета сам по себе информации не несёт.** Цвет — не текст: рядом всегда должно быть название («Красный»), иначе выбор недоступен и при дальтонизме, и на монохромном экране.
- Текст переносится (`text-wrap: pretty`), а не обрезается: подпись в форме важнее компактности.
- Disabled гасит ряд на 40% — контраст в этом состоянии заведомо ниже AA. Это нормально для выключенного контрола, но причина недоступности должна быть написана рядом текстом.

## Откуда берутся значения

| Что | Источник |
|---|---|
| Текст | `var(--awds-control-400-*)` — 14/20, одинаково на всех размерах |
| Цвет текста | `rgb(var(--surface-on-highest))` |
| Цвет подсказки | `rgb(var(--surface-on-high))` — роль `link/muted` |
| Обводка образца | `rgb(var(--surface-on-lowest))`, скругление `var(--awds-rounded-full)` |
| Заливка образца | **задаёт потребитель** — это цвет товара, а не роль DS |
| Бокс контрола и образца | `var(--awds-square-{N}-icon)` + `padding` |
| Зазоры | `var(--awds-space-2)` контрол↔текст, `var(--awds-space-1-5)` образец↔текст |
| Disabled | `var(--awds-opacity-40)` |

## Состояний у компонента нет

В макете оси State нет вовсе: hover, focus и active принадлежат вложенному контролу и живут в его скилле. Единственное правило состояния здесь — **disabled, и оно выведено**, а не снято с ячейки: без него строка была бы половинчатой — серый чекбокс со своим disabled-правилом и чёрная подпись рядом.

## Алгоритм использования

1. Возьми разметку нужного типа из [references/label-default.md](references/label-default.md).
2. Подключи `label.css` и рядом CSS тех контролов, которые используешь (`checkbox.css` / `radio.css` / `switch.css`).
3. Убедись, что на странице есть DS-токены (`--awds-square-*`, `--awds-control-*`, `--awds-space-*`, `--awds-opacity-*`, `--awds-font-*`) и сайтовый `css-variables.css` с ролями под классом `.theme-default.theme-light` на `<html>`.
4. Поставь размерный модификатор `.lbl--{N}` (если не указан, действует 400) — контрол внутри подхватит ступень сам.
5. Ширину задаёт родитель: строка тянется на 100%.
