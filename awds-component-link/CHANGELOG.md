# link — журнал версий

## 1.0.5 — 2026-09-18 — PATCH · visual
Цвет переведён с приватных ячеек State на роли: 20 ссылок, 20 якорей #cell. В опубликованной теме имён --awds-state-* нет, поэтому аккумулятор --awds-lnk-color не заполнялся и ссылка рисовалась наследуемым currentColor — у color-only компонента отсутствовал ровно цвет. Замер превью: 26 элементов, 155 свойств, все до единого цветовые. Собран макет: секция ↪ link была пуста, заведены пять наборов по варианту с осью state — 20 привязок ячеек.
Потребителю: Пересобрать CSS: ссылка впервые получает свой цвет вместо унаследованного. Разметка и классы не менялись.
