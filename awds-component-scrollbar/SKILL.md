# Scrollbar — полоса прокрутки

Класс ставится на элемент, который **уже прокручивается**. Своей разметки у компонента
нет: он не рисует ползунок, а красит тот, что рисует браузер.

- [references/scrollbar.md](references/scrollbar.md) — применение, стили, ограничения
- [references/preview.html](references/preview.html) — storybook: обе оси, default и transparent, тёмный островок

Макет — [↪ scrollbar, node 5:39](https://www.figma.com/design/470rar5EfRm4n14vHMXbpc/%F0%9F%92%A0-arrow-%E2%86%AA-components?node-id=5-39).

## Главное про контракт

```html
<div class="scrollbar" style="max-block-size: 240px; overflow: auto;">…</div>
<div class="scrollbar scrollbar-transparent" style="overflow-x: auto;">…</div>
```

**Компонент не задаёт `overflow` и размеры.** Он только красит полосу; где и насколько
область прокручивается — решение потребителя, и класс не должен менять раскладку.

**Прокрутку никто не перехватывает.** Колесо, тач, инерция, drag ползунка, клик по треку,
Shift+колесо, стрелки, автоскролл средней кнопкой — всё остаётся браузерным. Кастомный
ползунок на `div` пришлось бы переписывать целиком, включая эти привычки.

## Два API, и они несовместимы

| Что | Где работает | Что даёт |
| --- | --- | --- |
| `::-webkit-scrollbar*` | Chrome, Edge, Safari | точную геометрию макета: 6px, отступ 1px, радиус |
| `scrollbar-width` / `scrollbar-color` | Firefox | толщину «thin» и два цвета, без точных чисел |

**Их нельзя объявлять вместе.** С Chrome 121 наличие `scrollbar-width` отключает
псевдоэлементы, и вместо макетных 6px браузер рисует свою тонкую полосу. Поэтому
стандартные свойства стоят под `@supports not selector(::-webkit-scrollbar)` — то есть
включаются только там, где псевдоэлементов нет.

## Что решено в CSS, а не отдано потребителю

| Ситуация | Поведение |
| --- | --- |
| толщина | 6px (`space-1-5`), ползунок 4px за счёт прозрачной рамки 1px (`space-px`) с `background-clip: content-box` |
| наведение | ползунок 40% → 70% прозрачности; считается по **контейнеру**, а не по ползунку — в 4px курсором не попасть |
| вариант transparent | `.scrollbar-transparent` убирает трек, ползунок ложится прямо на содержимое |
| угол между полосами | красится цветом трека — иначе на тёмной подложке остаётся светлый квадрат |

## Токены

Ползунок — `rgb(var(--surface-on) / var(--awds-opacity-40))`, при наведении
`opacity-70`. Трек — `rgb(var(--surface-dim))`. Радиус — `rounded-full`. Толщина и
отступ — `space-1-5` и `space-px`. Своих значений нет.

## Размеры

Шкалы размеров у компонента нет: в макете одна толщина 6px для обеих осей.

## Чего в компоненте нет

- **Своего ползунка на `div`** — см. выше.
- **`scrollbar-gutter`** — резервирование места под полосу меняет раскладку, а это
  решение потребителя, не компонента.
- **Стилизации полосы страницы** (`html`/`body`) — класс вешается на конкретную область;
  глобальная полоса задаётся темой, а не компонентом.
