# Changelog — awds-component-scrollbar

Формат: версия · дата · уровень. Уровень описывает работу потребителя: MAJOR — править
разметку, MINOR — ничего, PATCH — пересобрать копию CSS. Флаг `visual_change` отдельно
отмечает, изменился ли вид.

## 1.0.0 — 2026-08-28 — INIT
Компонент собран из макета (node 2093:4230, 8 ячеек: Type × Style × State). Класс красит
нативную полосу прокрутки: толщина 6px, ползунок 4px за счёт прозрачной рамки, стили
Default (трек surface/dim) и Clear (трек прозрачный), наведение 40% → 70%. Своей
разметки и JS нет. Стандартные свойства для Firefox разведены с webkit-псевдоэлементами
через @supports — иначе Chrome 121+ игнорирует точную геометрию.
Потребителю: новый компонент, у потребителей его пока нет.
