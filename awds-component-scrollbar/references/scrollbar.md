## Применение

```html
<!-- вертикальная прокрутка списка -->
<ul class="scrollbar" style="max-block-size: 240px; overflow-y: auto;">…</ul>

<!-- горизонтальная лента, трек не нужен -->
<div class="scrollbar scrollbar-clear" style="overflow-x: auto;">…</div>

<!-- таблица с обеими осями -->
<div class="scrollbar" style="max-block-size: 60vh; overflow: auto;"><table>…</table></div>
```

`overflow` и размеры задаёт потребитель: класс красит полосу и не должен менять раскладку.

## Стили

| Класс | Трек | Когда |
| --- | --- | --- |
| `.scrollbar` | `surface/dim` | по умолчанию: видно, где полоса, даже когда ползунок короткий |
| `.scrollbar` + `.scrollbar-clear` | прозрачный | лента, карусель, тёмная подложка — там рамка полосы спорит с содержимым |

Ползунок в обоих случаях один: роль `surface/on` под `opacity-40`, при наведении на
область — `opacity-70`.

## Геометрия

| Что | Значение | Токен |
| --- | --- | --- |
| толщина полосы | 6px | `space-1-5` |
| ползунок | 4px | полоса минус отступ с двух сторон |
| отступ | 1px | `space-px` (в макете — padding трека) |
| радиус | pill | `rounded-full` |

Отступ сделан прозрачной рамкой ползунка плюс `background-clip: content-box`: `padding`
у `::-webkit-scrollbar-thumb` не работает, а рамка даёт тот же результат.

Проверено замером: у настроенной области полоса занимает **6px**, у ненастроенной в том
же браузере — 15px; переменные резолвятся в `#f2f2f2` (трек Default) и `transparent`
(Clear).

## Два API и почему они разведены

`::-webkit-scrollbar*` (Chrome, Edge, Safari) даёт точные числа макета.
`scrollbar-width` / `scrollbar-color` (Firefox) даёт только «thin» и два цвета.

**Объявлять их вместе нельзя.** С Chrome 121 наличие `scrollbar-width` отключает
псевдоэлементы: браузер нарисует свою тонкую полосу (~11px) вместо 6px. Поэтому
стандартные свойства объявлены под условием:

```css
@supports not selector(::-webkit-scrollbar) {
  .scrollbar { scrollbar-width: thin; scrollbar-color: … ; }
}
```

Цена: в Firefox толщина не 6px, а «тонкая» по мнению браузера, и отступ 1px недостижим.
Цвета при этом верные. Точную геометрию там не получить ничем — соответствующих свойств
в стандарте нет.

## Ограничения, о которых надо знать

- **Наведение — по контейнеру.** `:hover` на самом ползунке шириной 4px практически
  недостижим, поэтому подсветка включается, когда курсор над областью прокрутки.
- **Мобильные браузеры полосу не показывают** (оверлейная, появляется на время
  прокрутки) — это поведение системы, компонент на него не влияет.
- **Полоса страницы** (`html`) этим классом не красится: класс вешается на область.
- **Проверка в Firefox не автоматизирована.** Значения там задаются другими свойствами;
  сверка делалась расчётом, а не замером.
