# input-inline — журнал версий

## 1.0.0 — 2026-09-16 — MAJOR
Первый релиз. Компонент собран с нуля по секции ↪ input-inline (34:41032): поле ввода без рамки, фона, паддингов и слотов — базовый класс .iinline висит прямо на нативном <input>. Три тона (default · success · error) отвечают за валидацию, семь ступеней меняют только кегль. Код сразу на ролях и базовых шкалах, 51 якорь ячеек.
Потребителю: Новый компонент, у потребителей ничего не ломается. Берётся там, где редактируемость понятна из контекста — ячейка таблицы, строка списка, значение рядом с подписью.
