# Input Inline ArrowDS

Поле ввода **без оформления**: нативный `<input>` стоит прямо в потоке текста — ни рамки, ни фона, ни паддингов, ни слотов. Видно только сам текст; что поле редактируемо, читатель понимает по курсору и по кольцу фокуса.

Собран 16.09.2026 из секции [↪ input-inline](https://www.figma.com/design/470rar5EfRm4n14vHMXbpc/%F0%9F%92%A0-arrow-%E2%86%AA-components?node-id=34-41032) файла «💠 arrow ↪ components». Не правь `references/*.css` руками — затрётся при следующем refresh.

## Разметка

```html
<label for="qty">Количество</label>
<input class="iinline iinline-default iinline--400" id="qty" type="text" placeholder="Введите значение">
```

Базовый класс висит **на самом `<input>`**: обёртка не нужна, её нечем заполнить. Этим компонент и отличается от `awds-component-input`, где обёртка несёт рамку, фон и слоты.

## Когда брать его, а не input

| Ситуация | Компонент |
|---|---|
| Правка значения прямо в строке таблицы или в тексте | **`input-inline`** |
| Поле в форме — с рамкой, фоном, иконками | `awds-component-input` |
| Поле с подписью **внутри** рамки | `awds-component-input-combi` |

Рамка у поля — обещание: «здесь можно писать». Инлайн-поле такого обещания не даёт, поэтому годится там, где редактируемость понятна из контекста: ячейка таблицы, строка списка, значение рядом с подписью. В сплошной форме оно теряется.

## Тона

| Класс | Что значит | Ячейки |
|---|---|---|
| `.iinline-default` | Обычное поле | `form-control/default/{color,placeholder}-*` |
| `.iinline-success` | Значение принято | `form-control/success/…` |
| `.iinline-error` | Значение не принято | `form-control/error/…` |

Тона здесь про **валидацию**, а не про поверхность: фона и рамки нет ни у одного. Поэтому ряд короче, чем у `input` — три тона вместо семи.

До 16.09.2026 первый набор в макете звался `ghost`, хотя читал ячейки группы `default`. Решением владельца переименован: у поля без фона слово «ghost» ничего не отличает, а имя варианта обязано называть ту группу ячеек, которую вариант читает.

## Размеры

| Класс | Кегль | Высота |
|---|---|---|
| `.iinline--50` | 12 / 16 | 16px |
| `.iinline--100` | 13 / 16 | 16px |
| `.iinline--200` | 13 / 16 | 16px |
| `.iinline--300` | 14 / 20 | 20px |
| `.iinline--400` | 14 / 20 | **по умолчанию** |
| `.iinline--500` | 16 / 20 | 20px |
| `.iinline--600` | 16 / 20 | 20px |

Размер меняет **только кегль**: высота равна строке, поэтому семь ступеней дают две высоты. Шкала — `control`, не `typography`: у поля не должно быть адаптива по ширине окна.

## Откуда берутся значения

| Что | Источник | Где живёт |
|---|---|---|
| Цвет значения и плейсхолдера | роли `rgb(var(--secondary-container-*))`, `rgb(var(--success-container-*))`, `rgb(var(--error-container-*))` с якорем ячейки | `references/input-inline-{тон}.css` |
| Кегль | `var(--awds-control-font-size-{M})` и парные line-height / letter-spacing | ячейка `rectangle/{N}/typography` |
| Кольцо фокуса | `var(--awds-focus-color-muted)`, вариант `radius=none · offset=outside · tone=muted` | слой `awds-component-focus-selection` |
| Гашение | `var(--awds-opacity-40)` | ячейка `opacity/control/disabled` |

## Три вещи, которые легко сделать неправильно

1. **Не вешай класс на обёртку.** `.iinline` — это сам `<input>`. Обёртка со своим фоном вернёт поле к виду обычного `input`, ради отсутствия которого компонент и заведён.
2. **Фокус обязателен.** Единственный признак редактируемости, кроме курсора, — кольцо фокуса. Не гаси `outline` своим CSS и не подменяй его цветом текста: без рамки поле и так почти неотличимо от статичного значения.
3. **Подпись — снаружи и обязательна.** У поля нет ни рамки, ни плейсхолдера-подсказки в макете; `<label for>` или `aria-label` здесь важнее, чем у обычного input.

## Доступность

- Поле нативное: клавиатура, автозаполнение, типы и отправка формы работают сами.
- Кольцо фокуса — `:focus-visible`, брендовое при 50%, в 1px снаружи текста.
- Выключенное гасится до 40% — контраст в этом состоянии заведомо ниже AA, рядом нужен текст-причина.
- Размеры 50 и 100 меньше тач-минимума: только для мыши и плотных таблиц.
