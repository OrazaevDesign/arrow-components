# button-menu — журнал версий

> До версии 2.0.0 компонент назывался `button-profile` (базовый класс `.btn-profile`). Запись 1.0.0 говорит о нём. Отдельный компонент `button-lang` слит в этот же 31.08.2026 — своего журнала у него не было.

## 2.0.6 — 2026-09-15 — PATCH · visual
Код переведён с приватных ячеек State/Size на роли и базовые шкалы — 29 мёртвых ссылок, 22 якоря #cell. До починки кнопка рисовалась 32×32 без фона, обводки, отступов и зазора вместо 62×40 — 85 элементов превью из 181. В макете 60 шевронов перепривязаны со старой библиотеки: там жили опечатки chevrone и placehold, причём в наборе accent-selected шеврон стоял на ячейке подсказки.
Потребителю: Классы и разметка не менялись: контракт тот же. Кнопка обретает фон и обводку — если блок рисовал их сам, подгонку надо снять.

## 2.0.5 — 2026-09-14 — PATCH
Комментарии и описания в CSS приведены к новому имени ячейки темы: form-control/*/placehold и list/*/placehold стали placeholder после исправления опечатки по всей цепочке 14.09.2026. Значения и селекторы не менялись.
Потребителю: Ничего делать не нужно.

## 2.0.4 — 2026-09-14 — PATCH
Ячейка темы chevrone переименована в chevron: имя переменной и упоминания роли в документации приведены к правильному написанию. Значения не менялись.
Потребителю: Ничего: переменные приватные, ни один блок на них не ссылался.

## 2.0.3 — 2026-09-13 — PATCH
Примеры разметки переведены на .notice-accent вслед за notice 2.0.0.

## 2.0.2 — 2026-09-02 — PATCH
Инвариантные ячейки слоя State схлопнуты в одну без суффикса состояния (решение владельца 02.09.2026, план 2026-09-02 - state-vocab-decisions.md): компонент читает --awds-state-…-bg вместо четвёрки -rest/-hover/-focus/-active с одинаковыми значениями. Значения не менялись.
Потребителю: Разметка и классы прежние; блокам придёт обновлённая секция. Публикация блоков и темы — после Э3.

## 2.0.1 — 2026-09-01 — PATCH
Ссылки на слой State переведены с mode-less имён на плоские суффиксные: opacity/control-disabled → те же ячейки с суффиксом -rest. Значение не изменилось: у этих ячеек все четыре состояния (rest, hover, focus, active) несут одно и то же, поэтому -rest подставлен без потери смысла. Смысл правки — снять зависимость компонента от блоков-обёрток темы, которые переключают mode-less имена за него и новых компонентов уже не покрывают. Этап Э2 плана «Уплощение слоя State».
Потребителю: Ничего делать не надо: имена читаются внутри CSS компонента, разметка, классы и вид не менялись.

## 2.0.0 — 2026-09-01 — MAJOR · visual
Компонент переименован из button-profile в button-menu: базовый класс .btn-profile → .btn-menu, слот .btn-profile__avatar → .btn-menu__emblem, файлы references/button-profile.{css,md} → button-menu.{css,md}. Имя взято у самой вещи, а не у первого потребителя: кнопка открывает меню, и в круге у неё может быть аватар пользователя или флаг языка. Добавлена ось content = avatar | flag — сюда слит бывший отдельный компонент button-lang; класса у кнопки ось не получила (у avatar и flag не отличается ни один токен кнопки), значение несёт вид вложенной эмблемы: emb-img / emb-initials / emb-placeholder против emb-icon. Выбранность переведена с модификатора .btn-profile--selected на имя тона: .btn-menu-default и .btn-menu-accent-selected, по образцу list-item и по двум наборам макета; оси selected и состояния selected больше нет, тон в разметке обязателен. Появились размерные классы .btn-menu--400 / --300 / --200: шеврон в макете привязан к rectangle/{N}/icon, где у ступени 200 своё значение 16px против 20px. Зависимость avatar 2.0.1 заменена на emblem 3.0.0. Гашение переведено на var(--awds-state-opacity-control-disabled) вместо литерала --awds-opacity-opacity-40. Прозрачность шеврона снята: ячеек opacity/chevrone/{shrink,expand} в макете нет ни в одной из 60 ячеек, замер тёмнейшего пикселя даёт ровно цвет ячейки chevrone без множителя. Смещения точки-индикатора (-1px / 1px) убраны: по замеру макета точка стоит вплотную к углу круга на всех трёх ступенях. Цвет шеврона у accent-selected берётся из list/selected-secondary/chevrone — в макете стоит placehold, расхождение намеренное (решение Р6, реестр расхождений Р-14). Deprecated-наборы button-profile / initial и / icon сняты из скилла: в Figma их больше нет.
Потребителю: Разметку править обязательно. Заменить .btn-profile → .btn-menu, .btn-profile__avatar → .btn-menu__emblem, .btn-profile__badge → .btn-menu__badge, .btn-profile__chevron → .btn-menu__chevron; подключаемый файл теперь references/button-menu.css. Дописать два обязательных класса: тон (.btn-menu-default или .btn-menu-accent-selected) и ступень (.btn-menu--400 / --300 / --200) — без тона кнопка останется без фона и обводки. Модификатор .btn-profile--selected заменить на тон .btn-menu-accent-selected (класс не добавляется к default, а заменяет его). Внутри слота заменить аватар на эмблему: .avatar → .emb, .avatar-{img,initials,placeholder} → .emb-{…}, .avatar--{150,100,50} → .emb--{…}, и подключить references/emblem.css вместо avatar.css. Для флага языка — emb emb-icon emb--{150|100|50}; если флага нет, код языка текстом в emb emb-initials. Вид изменился: шеврон больше не гасится до 40% в rest, и точка-индикатор сдвинулась на 1px в оба измерения — посмотреть глазами. На 01.09.2026 потребителей нет ни одного (component-usage --check: 0 объявленных, 0 фактических), в блоках PageCraft класса .btn-profile нет, в публичном репозитории arrow-components компонент не публиковался — рассылка копий CSS не нужна.
