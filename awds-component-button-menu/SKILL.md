# Button Menu (кнопка меню) ArrowDS

Таблетка с круглой эмблемой и шевроном: нажатие раскрывает меню. В круге либо аватар
пользователя, либо флаг языка — это одна и та же кнопка, различается только содержимое
круга. Компонент **композитный**: круг и точка-индикатор — не свои узлы, а слоты под
готовые компоненты (`awds-component-emblem`, `awds-component-notice`), потому что в макете
там стоят их инстансы, а не нарисованные заново круги.

До версии 2.0.0 компонент назывался `button-profile`, базовый класс был `.btn-profile`.
Имя сменилось по правилу 3 канона (`arrow-components-builder/references/props.md`): имя
берётся у самой вещи, а не у первого потребителя. Кнопка не «кнопка профиля», а кнопка,
открывающая меню; профиль был лишь первым, кто её вставил. Вторым стал переключатель
языка — до 31.08.2026 он существовал отдельным компонентом `button-lang` и слит сюда как
значение оси `content`.

## Когда что

| Нужно | Компонент |
| --- | --- |
| Кнопка, раскрывающая меню: круг + шеврон | **`awds-component-button-menu`** (этот) |
| Просто круг с содержимым, без кнопки и шеврона | `awds-component-emblem` |
| Кнопка с текстом и заливкой | `awds-component-button` |
| Кликабельная область без фона | `awds-component-button-area` |

## Разметка

Полные примеры — [references/button-menu.md](references/button-menu.md).

```html
<button class="btn-menu btn-menu-default btn-menu--400" type="button"
        aria-haspopup="menu" aria-expanded="false" aria-label="Профиль">
  <span class="btn-menu__emblem">
    <span class="emb emb-img emb--150"><img src="/media/user.jpg" alt=""></span>
  </span>
  <svg class="btn-menu__chevron" viewBox="0 0 20 20" aria-hidden="true">…</svg>
</button>
```

Обязательны три класса: база, тон и ступень. Тон в базе не задефолчен намеренно —
подставленный дефолт скрыл бы пропуск класса и кнопка выглядела бы прозрачной без ошибки.

## Оси

| Ось | Значения | Где живёт |
| --- | --- | --- |
| **тон** | `default` · `accent-selected` | `.btn-menu-default` / `.btn-menu-accent-selected` |
| **size** | `400` · `300` · `200` | `.btn-menu--400` / `--300` / `--200` |
| **content** | `avatar` · `flag` | **класса у кнопки нет** — значение несёт вложенная эмблема |
| **badge** | есть точка / нет | наличие слота `.btn-menu__badge` в разметке |
| **state** | `rest` · `hover` · `focus` · `active` · `disabled` | псевдоклассы, `:disabled` / `[aria-disabled="true"]` |

**Выбранность — тон, а не состояние.** «Меню раскрыто» это `.btn-menu-accent-selected`, а
не модификатор `--selected` и не ось `selected=on|off`: дизайн-система выражает
выбранность именем варианта (`list/accent-selected`, `rating/selected`,
`tab/unselected`), и в макете это два отдельных набора — `button-menu / default` и
`button-menu / accent-selected`. Имена тонов взяты по образцу `list-item`, у которого те
же `default` и `accent-selected`.

**У оси `content` нет своего класса,** потому что у самой кнопки между `avatar` и `flag`
не отличается ничего: габариты, padding, gap, шеврон и все четыре цветовые ячейки
совпадают до значения. Отличается только инстанс в круге, и его вид кнопке приносит класс
эмблемы. Класс `.btn-menu-avatar` обещал бы разницу, которой нет.

| content | Что в слоте |
| --- | --- |
| `avatar` | `emb emb-img` · `emb-initials` · `emb-placeholder` — фото, инициалы или силуэт |
| `flag` | `emb emb-icon` — флаг языка на светлой подложке |

**Языку без флага — код текстом стилем инициалов.** Если флага для языка нет, в круг
ставится `emb emb-initials` с кодом (`KZ`, `EN`): вид у инициалов уже есть, а второй
графики для «языка без картинки» дизайн-система не описывает. Решение владельца ДС от
31.08.2026.

## Размеры

Ступеней три, и отличаются они **шевроном**: `rectangle/{N}/icon` даёт 20 / 20 / 16 px.
padding и gap у всех трёх одни (коллекция `profile-button` отдаёт по одному значению),
диаметр круга приносит эмблема своим классом. Высота считается сама:
`padding * 2 + max(эмблема, шеврон)`.

| Ступень | Класс эмблемы | Эмблема | Шеврон | Кнопка |
| --- | --- | --- | --- | --- |
| `btn-menu--400` | `emb--150` | 32px | 20px | 62 × 40 |
| `btn-menu--300` | `emb--100` | 28px | 20px | 58 × 36 |
| `btn-menu--200` | `emb--50` | 24px | 16px | 50 × 32 |

Ступени 400 и 300 читают разные ячейки (`rectangle/400/icon` и `rectangle/300/icon`),
которые сегодня резолвятся в одно значение — номер класса совпадает с номером токена, а
разойтись значения могут в студии без правки компонента.

## Откуда берутся значения

| Что | Источник |
| --- | --- |
| Фон и обводка `default` | `rgb(var(--awds-state-list-unselected-{bg,border}-{state}))` |
| Фон и обводка `accent-selected` | `rgb(var(--awds-state-list-selected-secondary-{bg,border}-{state}))` — по состояниям не меняются, поэтому правило одно |
| Цвет шеврона | `rgb(var(--awds-state-list-{unselected,selected-secondary}-chevron-{state}))` |
| padding / gap | `var(--awds-size-profile-button-{padding,gap})` |
| Размер шеврона | `var(--awds-size-rectangle-{400\|300\|200}-icon)` |
| Форма | `var(--awds-rounded-border-radius-full)` — таблетка |
| Кольцо фокуса | слой `awds-component-focus-selection`, вариант **Outside + Default** |
| Гашение | `var(--awds-state-opacity-control-disabled)` + `pointer-events: none` |
| Эмблема и точка | свои компоненты в слотах: `emb--{150\|100\|50}`, `notice notice-accent notice--100` |

Своих значений два: `0.15s` на переходах и `1px` — толщина обводки. Оба с причинами в
`own_values` меты; смещений точки среди них больше нет — по замеру макета она стоит
вплотную к углу круга.

**Расхождение с макетом, записанное намеренно.** Цвет шеврона у `accent-selected` код
берёт из `list/accent-selected/chevron`, а в макете стоит
`list/accent-selected/placeholder`: ячейки `chevron` в переменных Figma нет — экспорт
студия → Figma её не довёз. Решение владельца ДС (Р6 плана от 01.09.2026): правильный код
пишем сейчас, макет догоняет после экспорта. Находка — в
`plans/2026-08-25 - value-drift-registry.md`, Р-14.

## CSS

Один файл — `references/button-menu.css`. Оба тона живут в нём: между ними четыре
объявления разницы, и второй файл повторил бы всю базу и все размеры. Подключается один
раз глобально, **вместе с CSS компонентов из слотов**: `awds-component-emblem`
обязательно, `awds-component-notice` — если нужна точка, `awds-component-focus-selection`
— всегда (кольцо фокуса).

Визуальный QA — `references/preview.html` (storybook, `file://`): матрица ступень ×
состояние, переключатели тона / содержимого / точки, замеры через `btnMenuReport()` в
консоли.

## Заметки

- **Точка живёт внутри `.btn-menu__emblem`**, а не рядом с ним: в макете она прижата к
  углу бокса эмблемы, поэтому её привязка не зависит от ступени. Слоту обязателен
  `display: flex` — у инлайнового бокс равен строке (15px), и точка съезжает вниз.
- **Шеврон больше не гасится прозрачностью.** До 2.0.0 он читал ячейки
  `opacity/chevron/{shrink,expand}` (40 → 90 → 100%); в макете этой привязки нет ни в
  одной из 60 ячеек, а `opacity/control/{enabled,disabled}` привязана к самой ячейке, то
  есть к кнопке целиком. Замер: тёмнейший пиксель шеврона в `rest` — `#080808`, ровно
  значение `list/default/chevron-rest`, без множителя.
- **Цвет точки на hover кнопки не меняется**, хотя в макете он темнеет: точка — чужой
  компонент, и её `:hover`-правила принадлежат `awds-component-notice`. Лезть в её
  селектор из кнопки нельзя, поэтому расхождение записано вопросом в мете.
- `aria-expanded` и `.btn-menu-accent-selected` меняются вместе: класс про вид, атрибут
  про смысл.
