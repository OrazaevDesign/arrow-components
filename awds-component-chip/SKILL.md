# Чипс ArrowDS

Чипс — фильтр-переключатель на геометрии кнопки: та же шкала ступеней `rectangle`,
те же части (`prefix`, `text`, `suffix`), но своя группа цветов State `chip` и
выбранность. Значения не хардкодятся: роли и шкалы темы, см. `arrow-design-system`.

**Figma:** секция [↪ chip](https://www.figma.com/design/470rar5EfRm4n14vHMXbpc/%F0%9F%92%A0-arrow-%E2%86%AA-components?node-id=5-30),
страница «4 · elements»: наборы `chip / unselected` и `chip / selected`, 35 ячеек в
каждом (`size` 600…50 × `state` rest · hover · focus · active · disabled), булевы
`show-prefix` (по умолчанию выключен) и `show-suffix` (включён).

## Части

Части общие с кнопкой, секция «↪ parts» страницы «4 · elements». Зазор между иконкой и
краем у `. / prefix` и `. / suffix` — не внутренний отступ, а отдельный фрейм `gap`
шириной `rectangle/{N}/gap` на внешней стороне части. Его включает булево `show-gap`, по
умолчанию `true` (кнопки выглядят как раньше).

| Часть | Как стоит в чипсе | В коде |
| --- | --- | --- |
| `. / prefix` | `show-gap` = on, иконка — слот `ic-a` | `<svg>` первым ребёнком, цвет — цвет текста |
| `. / text` | подпись, отступы `rectangle/{N}/gap` с обеих сторон | текст |
| `. / suffix` | `show-gap` = **off**, `ic-a` = `system-close_circle-filled`, остальные слоты выключены | `.chip__remove` последним ребёнком, цвет — ячейка `icon-remove` |

**У крестика справа нет `gap`.** Поэтому у чипса с крестиком правый край — только
`padding` ступени (16 · 12 · 10 · 8 · 8 · 4 · 2 на 600…50), а не `padding + gap`, как у
чипса без крестика. В CSS это одно правило `.chip:has(> .chip__remove:last-child)`:
разметка потребителя не меняется, класс-модификатор не нужен.

До 19.10.2026 под это существовала отдельная часть `. / suffix-chips` (1128:7697); её
сменил `show-gap` у общего суффикса, и часть удалена.

## Когда брать

| Задача | Что |
| --- | --- |
| Фильтр, который включают и выключают на месте: «Со скидкой», «В наличии», цвет, размер в шторке | чипс-переключатель, `aria-pressed` |
| Строка применённых фильтров, где нажатие убирает фильтр | чипс с крестиком `.chip__remove` |
| Действие («Купить», «Сбросить все») | не чипс — `button` |
| Переключение разделов страницы | не чипс — `tab-group` |
| Вариация товара (цвет, размер в карточке) | не чипс — `tab-product` / `list-item` variation |

`btn-pills` у кнопки тоже называют «чипом», но выбранности у него нет: это кнопка
действия в форме пилюли. Если элемент помнит, включён ли он, — это чипс.

## Варианты

| Вариант | Reference | Когда |
| --- | --- | --- |
| **Unselected** | `references/chip-unselected.md` | фильтр выключен; серая поверхность, на hover и нажатии подсвечивается accent-контейнером |
| **Selected** | `references/chip-selected.md` | фильтр включён или применён; заливка primary |

Выбранность — **класс варианта**, а не ось состояния: так её называет слой State
(группа `chip`), так же устроены `tab-selected` / `tab-unselected`. Скрипт переключает
класс и `aria-pressed` вместе.

## Ступени

`.chip--{600|500|400|300|200|100|50}` — те же цели `rectangle/{N}`, что у `.btn--{N}`:
чипс 400 рядом с кнопкой 400 одной высоты (40 px). Без класса ступени — 400.

Форма всегда пилюля: в макете ячейки стоят в моде скругления Rounded, в коде —
`--awds-rounded-border-radius-full`. Отдельной оси формы нет.

## Разметка

```html
<!-- переключатель -->
<button type="button" class="chip chip-unselected chip--400" aria-pressed="false">
  Со скидкой
</button>

<!-- применённый фильтр: весь чипс — кнопка «убрать» -->
<button type="button" class="chip chip-selected chip--400" aria-label="Убрать фильтр: Красный">
  Красный
  <svg class="chip__remove" viewBox="0 0 20 20" aria-hidden="true"><!-- system-close_circle-filled --></svg>
</button>
```

Правила:

- корень — `<button type="button">`: чипс меняет состояние на месте, а не ведёт по адресу;
- переключатель несёт `aria-pressed`, без него скринридер не узнает, что фильтр включён;
- у чипса с крестиком `aria-label` начинается с действия и **содержит видимый текст**
  («Убрать фильтр: Красный»), иначе голосовое управление по подписи не найдёт кнопку;
- выключенный чипс — нативный `disabled`: `pointer-events: none` клавиатуру не гасит.

## CSS

`references/chip.css` — база, ступени и оба варианта одним файлом: в ряду фильтров
выбранные и невыбранные живут одновременно. Кольцо фокуса — ссылки на `--awds-focus-*`
слоя `awds-component-focus-selection`, его CSS подключается до чипса.

Визуальная проверка — `references/preview.html`.
