# Button Group

Склеенная группа кнопок: несколько `.btn` встык, внешние углы скруглены, стыки
прямые. Для действия с приклеенным дополнительным (отправить + выбрать
получателя), для пары «шаг назад / шаг вперёд», для основной кнопки с меню.

## HTML

Иконка справа (`side=end` в макете):

```html
<div class="btn-group">
  <button class="btn btn-primary btn--600" type="button">Button</button>
  <button class="btn btn-primary btn--600 btn--icon-only" type="button" aria-label="Ещё">
    <svg viewBox="0 0 20 20" aria-hidden="true">…</svg>
  </button>
</div>
```

Иконка слева (`side=start`) — тот же код, порядок узлов обратный. Иконки с обеих
сторон (`side=startend`) — три кнопки, текстовая посередине.

**Вариант и размер ставятся на КАЖДУЮ кнопку, а не на группу.** У группы своих
классов варианта и размера нет: `.btn-group` не знает, что внутри, и не должен
знать. Разные варианты в одной группе технически возможны, но в макете такого
нет — там все кнопки одного варианта.

## CSS

Три правила, больше в компоненте ничего нет:

| Что | Зачем |
| --- | --- |
| `display: inline-flex; align-items: center` | кнопки встык, без `gap` |
| `> :not(:first-child)` / `:not(:last-child)` — радиус стыка в `0` | внешние углы остаются те, что дала ступень кнопки |
| `> :focus-visible { z-index: 1 }` | кольцо фокуса не подрезается соседом |

Плюс `isolation: isolate` на группе — из макета и чтобы `z-index` не вылезал
наружу.

## Чего в компоненте нет

- **Своих цветов.** `get_variable_defs` на группе отдаёт только токены кнопок;
  группы `button-group` в слое State темы нет.
- **Своей шкалы размеров.** Геометрия целиком на `.btn--{N}`.
- **Классов варианта.** Семь фреймов в макете отличаются только вариантом
  вложенных инстансов — это ноль классов в CSS.
- **Вертикальной раскладки.** В макете только горизонтальная.

## Шов между кнопками — 2px

Кнопка рисует обводку через `box-shadow: inset 0 0 0 1px`, поэтому у двух
соседних кнопок на стыке встречаются две обводки: внешний край группы 1px,
внутренний шов 2px. **Так же и в макете** — замер `button-group / clean`,
`size=600, side=startend`: внешняя линия по 1px на x=0 и x=203, шов по 2px на
x=51–52 и x=151–152.

Схлопывать шов до 1px (отрицательный margin на соседях или снятие одной стороны
обводки) — распространённый приём в сегментированных контролах, но это
расхождение с макетом, и решает его автор. Вопрос записан в
`component.meta.json` → `questions[]`.
