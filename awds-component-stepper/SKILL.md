# Stepper ArrowDS

Степпер количества: «−», число, «+» на общей подложке вида кнопки. Заведён 21.11.2026 для
мини-карточки товара: в состоянии «в корзине» показывает, сколько штук лежит, и даёт менять
количество, не уходя в корзину.

**Макет:** [470rar5EfRm4n14vHMXbpc → набор 1413:56439](https://www.figma.com/design/470rar5EfRm4n14vHMXbpc/%F0%9F%92%A0-arrow-%E2%86%AA-components?node-id=1413-56439), страница «2 · buttons», секция `↪ stepper`.

## Разметка

```html
<div class="stepper stepper-secondary stepper--600" role="group" aria-label="Количество">
  <button class="btn btn-secondary btn--600 btn--icon-only" type="button" aria-label="Уменьшить на 1">
    <svg viewBox="0 0 20 20" aria-hidden="true">…минус…</svg>
  </button>
  <output class="stepper__value" aria-live="polite">2</output>
  <button class="btn btn-secondary btn--600 btn--icon-only" type="button" aria-label="Увеличить на 1">
    <svg viewBox="0 0 20 20" aria-hidden="true">…плюс…</svg>
  </button>
</div>
```

Вид и ступень ставятся **и на степпер, и на каждую кнопку**: `.stepper-secondary.stepper--600`
снаружи, `.btn-secondary.btn--600` внутри. Степпер держит подложку и число, кнопки — свои
состояния.

### На единице «−» становится корзиной

Ось макета `at-min=on`. В коде класса нет: меняются иконка и подпись кнопки.

```html
<button class="btn btn-secondary btn--600 btn--icon-only" type="button" aria-label="Удалить из корзины">
  <svg viewBox="0 0 20 20" aria-hidden="true">…корзина…</svg>
</button>
```

Нажатие убирает товар целиком. Иконка предупреждает об этом заранее, поэтому подтверждения
не нужно. Решение владельца 21.11.2026: «−», который на нуле молча удаляет товар (так у Atlas),
отвергнут — удаление случалось бы незаметно.

### Предел количества

Когда число дошло до остатка вариации, «+» выключается: `disabled` на кнопке. Своего
состояния у степпера для этого нет, выключенность приходит с кнопки.

## Оси макета → код

| Ось | Значения | В коде |
| --- | --- | --- |
| `size` | 600 · 500 · 400 · 300 | `.stepper--{N}` и `.btn--{N}` на кнопках |
| `view` | secondary · addition | `.stepper-{вид}` и `.btn-{вид}` на кнопках |
| `at-min` | off · on | иконка и `aria-label` кнопки «−», класса нет |

Ступени 200…50 не заведены: степпер нужен там, где по нему попадают пальцем.

## Что делает степпер

| Правило | Зачем |
| --- | --- |
| подложка и обводка на корне | у `addition` фон — градиент; если рисовать его на каждой кнопке, на стыках он начинается заново. Заливка та же, что у кнопки addition в покое: радиальное свечение сверху, слой 60% |
| кнопки в покое прозрачны | фон уже на корне; при наведении и нажатии кнопка подсвечивается своей формой |
| число уже кнопки: от 36 px на 600, от 32 px ниже | так в макете: число — часть кнопки «. / text». Боковые отступы `rectangle/N/gap` держат трёхзначное число от кнопок, степпер раздвигается. Ширина в покое — 140 / 120 / 112 / 104 px |
| `tabular-nums` у числа | 9 → 10 не сдвигает кнопки |
| `> :focus-visible { z-index: 1 }` | кольцо фокуса не подрезается соседом |

Фон кнопки гасится свойством `background`, без записи в приватные `--awds-btn-*`: иначе они
стали бы контрактом между компонентами.

## Доступность

- Корень — `role="group"` с подписью «Количество»: экранная читалка называет, что меняется.
- Число — `<output aria-live="polite">`: новое значение озвучивается после нажатия.
- У каждой кнопки свой `aria-label`: «Уменьшить на 1», «Увеличить на 1», «Удалить из корзины».

## Зависимости

`awds-component-button` — кнопки внутри и их состояния; `awds-component-focus-selection` —
кольцо фокуса. Подключаются на страницу до степпера.
