# Emblem / Icon

**Figma:** [470rar5EfRm4n14vHMXbpc → node 6:393](https://www.figma.com/design/470rar5EfRm4n14vHMXbpc/%F0%9F%92%A0-arrow-%E2%86%AA-components?node-id=6-393)

> [!NOTE]
> `emblem-icon.md` — **author-owned**. ACB пишет первичный draft, потом не трогает. CSS (`emblem.css`) и preview генерируются и при refresh затрутся.

Компактный круг под **произвольную** иконку: флаг языка, пиктограмма раздела, знак валюты. В макете содержимое — INSTANCE_SWAP-свойство `content`, то есть иконку подставляет потребитель.

Отличие от `emblem-placeholder`: там фиксированный силуэт человека на фирменной подложке и все десять ступеней; здесь любой знак на светлой `surface-bright`, без кольца и только три ступени.

## HTML

```html
<span class="emb emb-icon emb--150">
  <svg viewBox="0 0 24 24" aria-hidden="true">…</svg>
</span>
```

Иконка обязана быть квадратной: CSS задаёт ей одинаковые ширину и высоту.

## Поведение

| Свойство | Значение |
|---|---|
| Фон | `rgb(var(--surface-bright))`, сплошной — градиента нет |
| Кольцо | нет (`--awds-emb-border: transparent`) |
| Размер иконки | `var(--awds-space-N)`: 24px на `--150`, 20px на `--100`, 16px на `--50` |
| Цвет иконки | приносит сама иконка; монохромная на `currentColor` унаследует `primary-container-on-high` от базы |
| Скругление | `var(--awds-rounded-border-radius-full)` (всегда круг) |

**Цвет содержимого в макете не привязан** — в Figma по умолчанию стоит цветной флаг со своими заливками. Для монохромной MGC-иконки роли в теме нет; вопрос открыт в `questions[]` меты (`emblem-icon-content-color`).

## Размеры

Только `.emb--150` (32px), `.emb--100` (28px), `.emb--50` (24px). Других ступеней в макете нет — ступень без своего значения токена не заводится. На чужой ступени иконка возьмёт фолбэк 60% диаметра, но это не поддерживаемая комбинация.
