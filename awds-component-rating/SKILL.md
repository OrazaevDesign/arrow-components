# Rating — оценка звёздами

Пять звёзд. Два режима одной и той же разметки:

- **выбор** — внутри каждой звезды нативный `<input type="radio">`;
- **показ** (`.rating--readonly`) — инпутов нет, значение в `data-value`.

- [references/rating.md](references/rating.md) — разметка, режимы, поведение
- [references/preview.html](references/preview.html) — storybook: размеры, значения, тёмный островок

Макет — [↪ rating, node 6:850](https://www.figma.com/design/470rar5EfRm4n14vHMXbpc/%F0%9F%92%A0-arrow-%E2%86%AA-components?node-id=6-850).

## Главное про контракт

**Выбор держит нативный radio, а не JS.** Клик, стрелки, Tab, отправка формы и
объявление скринридером («переключатель, 3 из 5») — всё это поведение radio-группы,
которое не нужно переписывать. В компоненте **нет файла JS**.

```html
<fieldset class="rating rating--300">
  <legend class="rating__legend">Оценка</legend>
  <label class="rating__star">
    <input class="rating__input" type="radio" name="rate" value="1" aria-label="1 из 5">
    <svg class="rating__icon" viewBox="0 0 20 20" aria-hidden="true">
      <path class="rating__ghost" d="M9.78372 2.45422C9.88018 2.28871 10.1199…"/>
      <path class="rating__outline" d="M9.18227 1.85051C9.59488 1.32318 10.4055…"/>
      <path class="rating__solid" d="M9.10047 1.97602C9.50228 1.28616 10.4985…"/>
    </svg>
  </label>
  <!-- ещё четыре такие же звезды: value 2…5 -->
</fieldset>
```

**Три контура в каждой звезде, а не один.** В макете выбранная звезда — сплошная
(`shape-star-filled`), пустая — дуотон (`shape-star-duotone`: контур плюс заливка на 30%).
Это разные векторы, поэтому оба лежат в разметке, а CSS переключает видимость слоёв
переменной `--awds-rating-picked`. Полные значения `d` — в
[references/rating.md](references/rating.md).

**Порядок звёзд в разметке прямой — 1, 2, 3, 4, 5.** Распространённый приём «обратный
DOM + row-reverse» даёт ту же картинку, но разворачивает клавиатуру: стрелка вправо
уводила бы на визуально левую звезду.

**Значение — это отмеченный input, а не класс.** Ось `Variant=1star…5star` из макета —
шкала для дизайнера; в коде оценка одна, и живёт она в `checked`.

## Что решено в CSS, а не отдано потребителю

| Ситуация | Поведение |
| --- | --- |
| выбрана третья звезда | подсвечены первая, вторая и третья: красим все, гасим те, что после выбранной |
| курсор на звезде | предпросмотр оценки — подсветка до неё, текущий выбор временно перебит |
| фокус с клавиатуры | кольцо слоя `focus-selection`, вариант Formcontrol, только `:focus-visible` |
| нужен показ без выбора | `.rating--readonly` + `data-value="4"`, инпутов нет вовсе |
| выключено | атрибут `disabled` на инпутах; класс `.rating--disabled` только красит |
| `prefers-reduced-motion` | переход цвета выключается |

## Токены

Цвета — роли: набранная звезда `rgb(var(--warning-core))`, на наведении
`rgb(var(--warning-dim))`, пустая `rgb(var(--surface-container-container))`.
Геометрия — шкала `space`: звезда `space-5 / space-4` (20/16), зазор `space-0-5` (2px).
Гашение выключенного — `var(--awds-opacity-40)`. Своих значений нет.

Роли стоят прямо в CSS, а не ячейками `--awds-state-rating-*` и
`--awds-size-square-N-icon`: коллекции State и Size приватные с 03.09.2026, этих имён
в опубликованной теме нет. До 15.09.2026 компонент читал их все и **не рисовался
вовсе** — звёзды выходили 0×0, а заливка падала в чёрный по умолчанию SVG. Цели взяты
из `component-token-map.json`, значения не подбирались.

**Почему размер лежит на ступени иконки, а не на произвольном шаге Space.** До 2.0.0
звёзды были 20/16/12 прямо со шкалы Space и в ступени `square-N-icon` (20/20/16) не
попадали — расхождение висело открытым вопросом. Закрыто подгонкой звёзд под
существующую шкалу: 12px больше нет, осталось две ступени. В коде теперь стоят цели
этих ступеней (`square/300/icon` → `space-5`, `square/200/icon` → `space-4`), но
смысл прежний: размер звезды двигает тот же токен, что двигает иконки остальных
компонентов.

## Размеры

`.rating--{N}`, N — `300 200`. Меняется диаметр звезды, зазор одинаков. По умолчанию — 300.

## Чего в компоненте нет

- **Половин звезды.** В макете их нет, а «4.5» в показе требует второй иконки или
  градиентной маски — заводить это без макета значит придумывать за дизайнера.
- **Своего JS.** См. выше: состояние держит radio. Если потребителю нужно отправить
  оценку сразу по клику — он вешает `change` на `.rating__input`, разметку менять не надо.
