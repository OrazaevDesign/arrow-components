# Changelog — awds-component-rating

Формат: версия · дата · уровень. Уровень описывает работу потребителя: MAJOR — править
разметку, MINOR — ничего, PATCH — пересобрать копию CSS. Флаг `visual_change` отдельно
отмечает, изменился ли вид.

## 1.0.0 — 2026-08-27 — INIT
Компонент собран из макета (node 2093:3766, 15 ячеек: Size × Variant). Пять звёзд, выбор
нативной radio-группой без единой строки JS, режим показа через data-value, размеры
400/300/200. Звезда рисуется тремя контурами: дуотон (контур плюс заливка на 30%) для
пустой и сплошная для набранной — в макете это разные векторы.
Потребителю: новый компонент, у потребителей его пока нет.
