# Tab ArrowDS

Одна вкладка с подчёркиванием — элемент переключения разделов внутри страницы.
Размеры, цвета и шрифт берутся из токенов DS, ничего не хардкодится. Общая картина
токенов — `arrow-design-system`, регенерация этого скилла из Figma —
`arrow-components-builder`.

**Вкладка — не группа вкладок.** Здесь один элемент. Полоса вкладок с прокруткой,
переполнением и раскладкой — отдельный компонент `tab-group`; выбор вариации
товара — `tab-product`.

**Не путать с `list-item`.** У того есть вариант `tabbar` — это вкладка нижнего
таббара мобильного приложения (иконка над подписью, вся строка кликабельна). Здесь —
горизонтальная вкладка с подчёркиванием внутри страницы.

## Оси

| Ось | Значения | Как выражается |
| --- | --- | --- |
| выбранность | `selected` · `unselected` | класс варианта `.tab-selected` / `.tab-unselected` |
| `size` | `400` · `300` | класс размера `.tab--400` / `.tab--300` |
| `state` | `rest` · `hover` · `focus` · `active` · `disabled` | псевдоклассы и нативный `disabled` |
| `badge` | есть / нет | вложенный инстанс `notice`, необязательный |

**Выбранность — вариант, а не состояние.** Оси `state=selected` в закрытом словаре
ArrowDS нет: дизайн-система выражает выбранность именем варианта, за которым стоит
группа ячеек темы (`tab/selected/*`, `tab/unselected/*`). В макете это два набора
(`tab / underline-selected` и `tab / underline-unselected`), в коде — два класса.

**Вид `underline` в имени класса не отражён.** Сегодня он единственный; когда
появится второй (залитая вкладка), он придёт вторым вариантом, а не переименованием.

## Разметка

Корень — нативная `<button type="button">` с `role="tab"` и `aria-selected`.

```html
<button type="button" class="tab tab-selected tab--400" role="tab" aria-selected="true">
  Отзывы
</button>

<button type="button" class="tab tab-unselected tab--400" role="tab" aria-selected="false">
  Характеристики
  <span class="notice notice-accent">12</span>
</button>

<button type="button" class="tab tab-unselected tab--300" role="tab" aria-selected="false" disabled>
  Доставка
</button>
```

| Обязательно | Почему |
| --- | --- |
| `.tab` | база: раскладка, геометрия, подчёркивание, кольцо фокуса |
| `.tab-selected` / `.tab-unselected` | цвета инлайнятся в вариантных селекторах; без класса варианта вкладка бесцветная |
| `.tab--400` / `.tab--300` | геометрия приходит только из size-класса; без него вкладка бесформенная |
| `role="tab"` | без роли выбранность не доезжает до скринридера: она выражена классом, а класс — не семантика |
| `aria-selected` | то же самое, вторая половина: роль без состояния сообщает «вкладка», но не «эта открыта» |
| `disabled` (когда выключена) | `.tab:disabled` только красит. `pointer-events: none` гасит мышь, но не клавиатуру — без атрибута выключенная вкладка активируется с `Enter` |

**Почему `<button>`, а не ссылка.** Вкладка переключает панель в пределах страницы,
а не ведёт по новому адресу; `<a>` пообещал бы переход, открытие в новой вкладке и
копирование ссылки, которых нет. Нативная кнопка бесплатно даёт активацию с
клавиатуры, `:disabled` и фокус. Если переключение секций всё-таки навигация (адрес
меняется, страница перезагружается) — это не вкладка, а `button-area` или
`list-item`.

**Что даёт группа, а не элемент.** `aria-controls`, `id` панели, `tabindex` роving и
обёртка `role="tablist"` — контракт `tab-group`: одна вкладка не может гарантировать
существование панели. В требования разметки они поэтому не вынесены.

## Размерная шкала

Shape — `rectangle`, та же, что у остальных контролов.

| Класс | padding-block | gap | кегль | высота |
| --- | --- | --- | --- | --- |
| `.tab--400` | `rectangle/400/padding` = 10 | `rectangle/400/gap` = 6 | 14 / 20 | 40 |
| `.tab--300` | `rectangle/300/padding` = 8 | `rectangle/300/gap` = 6 | 14 / 20 | 36 |

Ступеней две, потому что шкала сужена решением владельца ДС 01.09.2026 (Р4):
ступень заводится там, где у неё своё значение токена.

**Кегль одинаковый на обеих ступенях — это не ошибка.** `rectangle/300/typography` и
`rectangle/400/typography` обе указывают на `control-font-size-400` = 14 px. Решение
01.09.2026: вкладка остаётся в одной шкале с остальными контролами, откуда берёт всю
геометрию. Группа `size/tabs/400/typography` даёт 16 px, но её не читает ни один
компонент, и она подлежит приведению к `rectangle` — её значения подставлять нельзя.

**Горизонтального паддинга у вкладки нет.** В макете он 0 слева и справа: зазор между
вкладками даёт контейнер (`size/tabs/{N}/gap-panel`), а не сама вкладка.

## Счётчик

Счётчик — вложенный **`awds-component-notice`**, а не свой элемент вкладки: в макете
это exposed-инстанс `notice / accent`, включаемый пропом `badge`.

Ступень счётчика едет **мостом** `.tab--{N} .notice` — `tab 400 → notice 400`,
`tab 300 → notice 300`. Мост весит `(0,2,0)` против `(0,1,0)` у `.notice--{N}`,
поэтому класс размера у счётчика писать не нужно и он не перебьёт мост при любом
порядке подключения файлов.

## Что берётся из темы

| Что | Источник |
| --- | --- |
| фон, подчёркивание, цвет текста | слой State, группа `tab`: `--awds-state-tab-{selected\|unselected}-{bg\|border\|color}-{rest\|hover\|focus\|active}` |
| padding, gap | `--awds-size-rectangle-{400\|300}-{padding\|gap}` |
| кегль | `--awds-size-rectangle-{400\|300}-typography` |
| интерлиньяж, трекинг | `--awds-control-line-height-400`, `--awds-control-letter-spacing-400` |
| шрифт | `--awds-font-family-system`, `--awds-font-weight-semibold` |
| гашение | `--awds-state-opacity-control-enabled` / `-disabled` — тон слоя State, а не литерал `--awds-opacity-40` в обход слоя |
| кольцо фокуса | `--awds-focus-width` / `-color` / `-offset` из `awds-component-focus-selection` (вариант radius=none · offset=outside · tone=default) |
| размеры счётчика | `--awds-size-notice-{400\|300}-*` через мост |

**Своё значение одно** — толщина подчёркивания `2px`: ячейки толщины линии в теме
нет (`Space/px` — шкала отступов, не толщин). Заявлено в `own_values` меты.

## CSS-файл

`references/tab.css` — база, обе ступени, мост к счётчику и оба варианта со всеми
состояниями. **Файл один на два варианта намеренно:** в любом таббаре одновременно
живут и выбранная, и невыбранные вкладки, поэтому разложить их по двум файлам значило
бы заставить каждого потребителя подключать оба и дважды получить одну и ту же базу.
Тот же приём, что у `notice`.

## Storybook

`references/preview.html` — матрица «ступень × состояние» на обоих вариантах,
переключатель темы, счётчик, проверка высоты замером.

## Refresh

```
обнови awds-component-tab под Figma
```

ACB зайдёт по ссылкам из `component.meta.json`, снимет актуальные `variable_defs`,
сравнит со снапшотом, покажет diff и обновит CSS и preview. `SKILL.md` и
`{variant}.md` не трогает.
